# KaJ-App

KAJ is a Bangla-first local work and service marketplace planned for a pilot in Rajshahi, Bangladesh.

## Current status

The repository is in Phase 0: research, validation, and pre-build planning. Product code must not begin until the Phase 0 deliverables have been reviewed by the owner, as required by the master build guide.

## Project documents

- `KAJ_BUILD_GUIDE.md` — authoritative build contract, architecture, task order, and acceptance gates.
- `KAJ_UI_REQUIREMENTS.md` — user requirements, UI rules, accessibility requirements, and traceability.
- `KAJ_PREBUILD_PLAN.md` — legal, operational, vendor, staffing, cost, and launch dependencies.
- `docs/BUILD_PLAN.md` — executable task sequence and gate plan.
- `docs/COMPLETION_TRACKER.md` — live progress ledger and next task.
- `docs/completed/` — one detailed completion report for every finished step.

## Working rule

Every step follows: read requirements → restate scope → plan → test first where applicable → implement → verify → document → commit → push. A step is not marked complete if its required tests or acceptance checks fail.
