# P1-UI-08 — Authentication Entry Hardening

Completed locally on 1 September 2026.

## Scope delivered

- Android activity namespace aligned with the application namespace
- splash, phone, OTP, and authenticated landing routes protected by session state
- session restoration allowed to complete without a late timeout race
- OTP expiry feedback, 30-second resend cooldown, and replacement challenges
- single coordinated rotating-token refresh across concurrent expired requests
- idempotency keys added to DELETE requests
- malformed API error envelopes mapped to safe failures
- release builds use an explicit `key.properties` signing configuration when supplied and never silently use debug signing
- Flutter and CI aligned on Flutter 3.47.2 with `intl` 0.20.3
