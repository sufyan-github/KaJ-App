# Seeds and reference data (P0.8)

| Script                | Command                                                                               | Where it may run                                                                                         | What it writes                                                                                                                                                                                                                                                              |
| --------------------- | ------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Reference-data loader | `corepack pnpm --filter @kaj/backend seed:reference` (add `--dry-run` to only report) | **Any environment, including production.** Needs an explicit `DATABASE_URL`.                             | Creates missing categories, skills and Rajshahi locations (city → 4 thanas → 15 areas, Bangla + English). Never updates or deletes an existing row, so admin edits survive. No accounts, credentials, flags, settings or fees. One transaction. Re-running creates nothing. |
| Development seed      | `corepack pnpm --filter @kaj/backend seed`                                            | `NODE_ENV=development` or `test` only (refuses before connecting)                                        | Reference data (same source, `prisma/reference-data.ts`) plus the local admin, all feature flags **off**, config, fee rule, plan, badges. Resets those on every run — never point it at a shared database.                                                                  |
| Demo seed             | `corepack pnpm --filter @kaj/backend seed:demo`                                       | `NODE_ENV=development` or `test` only (allowlist; it used to run whenever NODE_ENV was not `production`) | 4 demo accounts in the unassigned `+88010` range (never a real subscriber; they cannot sign in, as sign-in accepts Robi/Airtel numbers only), 8 demo jobs with fixed ids, 3 applications. Idempotent.                                                                       |
| Training content      | `corepack pnpm --filter @kaj/backend seed:training [--publish]`                       | Any                                                                                                      | Upserts courses by slug.                                                                                                                                                                                                                                                    |

`test/seeds.prisma.e2e-spec.ts` runs each of the first three twice on a
fresh throwaway database in CI and checks the second run changes nothing.

Area centre coordinates (`locations.lat/lng`) are not in the reference data
yet; nearest-first matching uses worker and job points until they are added.
